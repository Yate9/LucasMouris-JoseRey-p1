🏋️ AlwaysFit — Página web de pérdida de grasa
📌 Descripción del proyecto

AlwaysFit es un proyecto de desarrollo web centrado en la pérdida de grasa corporal y la mejora de la condición física. Su objetivo es ofrecer una página web atractiva, moderna y fácil de utilizar, con información y recursos que ayuden a los usuarios a comprender cómo mejorar su composición corporal y adoptar hábitos saludables.

El diseño está orientado al mundo del fitness, combinando una estética deportiva con una estructura visual clara e intuitiva.
